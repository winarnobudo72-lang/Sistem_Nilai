Konfigurasi Online

Integrasi GitHub Pages & Cloud Database

Karena GitHub Pages bersifat statis, aplikasi ini menyimpan data secara lokal di browser dan mendukung sinkronisasi ke Google Sheets (via Google Apps Script) agar nilai seluruh siswa terkumpul otomatis dalam satu database online.

Kosongkan jika hanya menggunakan penyimpanan lokal browser & kode laporan siswa.

Cara Online-kan di GitHub Pages

  1. Buat repository baru di GitHub (misal: nilai-informatika-smpn2).
  2. Unggah file HTML ini dan ubah namanya menjadi index.html.
  3. Buka menu Settings → Pages, pilih branch main lalu klik Save.
  4. Tautan aplikasi siap dibagikan ke siswa kelas VIII dan IX.
Kode Google Apps Script (Opsional): 
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var d = JSON.parse(e.postData.contents);
  sheet.appendRow([d.id, d.name, d.studentClass, d.absent, d.assessment, d.score, d.status, d.note, d.timestamp]);
  return ContentService.createTextOutput(JSON.stringify({result:"success"})).setMimeType(ContentService.MimeType.JSON);
}
function doGet() {
  var rows = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet().getDataRange().getValues();
  var out = rows.slice(1).map(r => ({id:r[0], name:r[1], studentClass:r[2], absent:r[3], assessment:r[4], score:Number(r[5]), status:r[6], note:r[7], timestamp:r[8]}));
  return ContentService.createTextOutput(JSON.stringify(out)).setMimeType(ContentService.MimeType.JSON);
}
